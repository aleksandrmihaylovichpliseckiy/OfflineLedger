# 自动记账（OfflineLedger）

一个**完全离线**的个人记账 Android 应用：自动从**指定号码的银行短信**和各应用**支付通知**里读取收支，可选通过**无障碍服务**读取微信 / 支付宝账单与余额，自动生成可复制的**日报 / 周报 / 月报 / 年报**并用系统通知发给你。

- 软件名：**自动记账**；版本 **beta v1.2.3**（versionCode 7，包名 `com.ledger.offline` 不变，可直接覆盖升级）
- 技术栈：Kotlin 1.9.24 + Jetpack Compose（Material 3）+ Room 2.6.1 + WorkManager + DataStore
- `minSdk 26` / `targetSdk 34`；不声明 `INTERNET` 权限，所有数据只在本机
- 多语言：简体中文 / English / 日本語 / Русский（475 条文案已翻译）
- 六种主题色调 + 日间/夜间/跟随系统 + 图标配色（跟随主题 / 手动）

> **构建状态**：本工程已使用 JDK 17.0.13 + Android SDK 34 + Gradle 8.7 实际编译通过；
> `assembleDebug` / `assembleRelease` 均 BUILD SUCCESSFUL，单元测试通过，
> release APK 已用 `apksigner` 校验（v2 + v3）。

## 1. 功能

### 1.1 导入、去重与基金
- **银行短信**：只解析启用号码与回溯天数内的短信；解析金额 / 方向 / 余额 / 尾号 / 商户。
- **余额修正**：设置 → 账户管理 → 余额修正；读取每个账户最后一条带余额的流水，
  用短信里记录的余额修正账户余额，没有余额信息的账户跳过。银行短信导入时也会自动刷新余额。
- **数据保留**：覆盖升级不清空数据库；Room 只做增量迁移，并在打开数据库前把上一版本
  `ledger.db` 备份到应用私有目录 `files/upgrades/`（保留最近几个版本）。
- **通知**：设置 → 动账信源 → 需要解析支付通知的应用；可搜索、勾选应用，并对每个应用筛选通知类型
  （支出 / 收入 / 退款 / 转账 / 其他，默认全选）。
- **屏蔽词**：动账信源 → 屏蔽词清单（默认折叠）；短信 / 通知命中任一屏蔽词即不统计。
- **自动去重**：每条流水入库（短信 / 通知 / 手动记账）都会按金额、时间（≤3 分钟）、支出去向核验；
  自动托管（beta）自动合并、每次询问在主页逐组确认、关闭则不去重。主页「一键核验」可扫描最近 90 天历史记录。
- **手动记账同步余额**：手动新增一笔支出 / 收入会直接增减所选账户余额；编辑会先回退旧金额再按新金额同步，
  删除会自动回退。读取到银行短信后，短信余额会覆盖手动结果（以短信为准）。
- **基金**：短信来源里勾选“基金购买不计入支出”后：
  - 基金 / 理财申购 → 不记支出，金额转入“基金余额”账户；
  - 基金 / 理财赎回 → 不记收入，金额从“基金余额”扣除，银行余额仍按短信更新；
  - 基金流水以“转账”类型保存在明细里，不计入收入/支出统计。
- **信任模式**：主页「自动更新」/「支付宝余额」通过无障碍读取账单与余额；读取延迟默认 5 秒可调。

### 1.2 报表与分析
- 日报 / 周报 / 月报 / 年报，纯文本可复制、可通知；日报时间与周/月/年日期可自定义（折叠二级滚轮菜单）。
- 收支默认模式 / 月结模式；简易模式只保留收支总额。
- 分析页：**近 7 天收支趋势（默认）**、月趋势、年趋势、年际趋势；柱状图 / 折线图；收入/支出结构饼图。
- 首页“近 7 天收支趋势”横轴只显示“日”，大字号 / 小屏不再显示重复月份或被截断。

### 1.3 首页与明细
- 首页汇总卡 / 账户余额 / 趋势 / 最近流水 / 快捷操作均可排序、隐藏、删除（Snackbar 可撤销）。
- 任意页面点底部“首页”都会回到首页顶部。
- 明细显示收入来源 / 支出去向 / 账户 / 秒级时间；支持筛选、编辑、删除。
- 账户：新增 / 编辑 / 删除（有流水时拒绝）/ 排序；主页余额可按余额 / 流水 / 设定顺序排序。
- 默认账户：微信 / 支付宝 / 银行卡；基金账户在首次基金短信时自动创建。

### 1.4 外观与设置
- 6 种色调（墨绿 / 钴蓝 / 暮紫 / 暖橙 / 樱花粉 / 黑白）；日间 / 夜间 / 跟随系统；密度三档。
- 图标配色跟随主题或手动指定（启动器别名切换）。
- 设置页：短信来源 / 外观与语言 / 分类管理默认折叠；使用场景整行开关 + 状态小点；
  当前版本 / 关于自动记账（点击版本查看更新日志）；自动更新读取延迟。

## 2. 首次使用

1. 授予短信权限（设置 → 短信读取权限）。
2. 短信来源里启用银行号码，账户可选“自动建卡”；如需基金跟踪勾选“基金购买不计入支出”。
3. 授予通知使用权，并在“动账信源”勾选需要解析的应用与通知类型。
4. （可选）信任模式：授权无障碍服务，按需调整读取延迟。
5. 设置自动去重方式；回首页扫描或等待自动导入。

## 3. 技术架构

```
app/src/main/java/com/ledger/offline/
├── domain/          # 模型 + 仓库接口（TxType.TRANSFER / AccountType.FUND / NotificationKind）
├── data/            # Room / DataStore / 种子数据 / 余额增量调整
├── ingest/          # 短信、通知解析；屏蔽词、通知类型、基金分支
├── dedupe/          # 全来源去重：匹配、保留优先级、待询问、合并
├── report/          # 报表格式化、通知、WorkManager
├── ax/              # 信任模式无障碍（读取延迟）
├── i18n/            # 中 / 英 / 日 / 俄
├── ui/              # 主题、导航、页面、图标切换、首页回顶
└── util/            # Money / DateTimes / LayoutPrefs / FilterPrefs
```

- 完全离线：无 `INTERNET`，无第三方 SDK，`allowBackup="false"`。
- `QUERY_ALL_PACKAGES` 仅用于“需要解析支付通知的应用”列表，本机展示、不上传。

## 5. 已知限制

1. **去重是启发式**：金额完全相等 + 时间 ≤3 分钟 + 商户相似；允许同来源配对后，
   “同商户同金额 3 分钟内两笔真实消费”可能被误合并（自动托管 beta 风险更高），建议先用真实交易验证。
2. **基金识别依赖短信关键词**：需同时出现“基金/理财”与“申购/认购/购买/买入/定投”或“赎回/卖出/转出”；
   部分银行模板可能识别不到。历史已按支出记录的基金短信不会自动迁移，需要手动调整。
3. **通知类型分类**按关键词（退款/收款/转账/支付等），非官方分类；筛选过严可能漏记。
4. **屏蔽词**对短信/通知原文做包含匹配，可能误伤；建议只放非常明确的词。
5. **信任模式**仍受微信/支付宝页面改版影响，失败用「读取当前页」兜底。
6. **图标换色**通过启动器别名，切换后桌面刷新可能延迟；升级后旧快捷方式可能需重新添加。
7. **定时报表**受 WorkManager 省电策略影响可能延迟或缺失。
8. **语言**：界面文案已翻译；用户数据（账户/分类/商户/短信原文）保持原文；通知渠道名不随语言变化。
9. **日间/夜间**只影响 Compose 界面配色，系统状态栏仍使用主题色。
10. **手动记账余额同步**：余额未知（null）的账户按 0 起算且不会被手动支出减成负数；
    旧版本已存在的手动流水不追溯调整余额（避免与历史短信余额重复计算），但再次编辑时会按新金额同步；
    手动结果与银行短信冲突时以短信为准，下一次读取短信会覆盖。
11. **余额修正**只读取已入库流水里保存的短信余额；若某账户从未导入过带余额的短信、或最后一条短信
    没有余额字段，会跳过该账户。不同银行的短信模板仍可能有差异，识别不到时可在账户管理里手动改余额。
12. **升级备份**保存在应用私有目录，卸载应用会一并删除；当前版本未提供“从备份还原”的界面，
    仅作为迁移异常时的本地兜底。
